# Анализ набора данных Титаник с Kaggle

Данная работа подрузумевает под собой работу с набором данных титаник. В данной работе мы заполним пропуски в наборе данных и найдем процент выживаемости на титанике. Анализ будет произведен для разных возрастных групп и разных классов обслуживания.

---
### 🧰 Инструменты

В данной работе использовался язык программирование Python. Для выполнения также были использованы следующие библиотеки: Pandas, Seaborn, Matplotlib.

---
### 📋 Инструкция к запуску

Вам нужно установить [python](https://www.python.org/downloads/) на вашу систему. Затем вам нужно установить библиотеки из файла requirements.txt. Это можно сделать командой pip install requirements.txt и запустите файл Titanic_anylisis.py готово!
